0. 导论：如何读整本圣经

读经不是搜罗「金句」安慰自己，也不是把圣经当作道德格言集。改革宗认信：圣经是神所默示的权威话语（提后 3:16–17），其总意是以基督为中心显明神的救赎（路 24:27, 44–47；约 5:39）。

改革宗释经原则

方法

文法—历史释经

按原文语法、文学体裁、历史背景与正典语境解经；字义优先，寓意不可凌驾作者原意。比利时信条第 2–7 条强调圣经充足与权威。

规范

以经解经

较清楚经文解释较难解经文；整本正典互释。海德堡要理问答 Q&A 19、21 指向福音应许的整全启示。

中心

基督中心

旧约预表、应许、影儿指向基督；新约成就并解明。不是随意「找耶稣」，而是追踪神的救赎承诺如何在历史中应验。

应用

律法与福音

律法暴露罪、引导生活；福音宣告基督已完成的救赎。二者不可混淆，也不可割裂（参见海德堡 Q&A 2–3、86–91；多特教义总论）。

拒斥：自由派历史批判否定超自然；极端寓意解经不顾作者原意；道德主义把圣经当「怎样成功」手册；忽视圣约与教会群体的个人主义读经。

阅读路径建议

  1. 先宏观：正典结构 → 救赎历史时间线 → 圣约框架（本站第 1–3 章）。
  2. 再主线：国度、圣殿、献祭、后裔、余民、弥赛亚（第 4 章）。
  3. 后分卷：用「背景·目的·提纲·神学·基督·应用」六栏精读（第 5、7 章）。
  4. 专攻节点：诸王与被掳归回是旧约叙事枢纽（第 6 章）。
  5. 以信条校准：疑难处以三大信经与三项联合信条护卫正统（第 8 章）。

3. 圣约神学核心

欧陆改革宗以行为之约 / 恩典之约总框架理解整本圣经（参见比利时信条第 17、22–23 条；海德堡 Q&A 12–18、20–23）。神与人的关系总是「立约」的关系，而非抽象神秘主义。

两大总约

行为之约（与亚当）

完美顺服得生命（创 2；何 6:7 传统理解）。亚当为全人类代表；违约带来罪与死的归算（罗 5:12–21）。

基督作为末后亚当，以主动与被动顺服成全义。

恩典之约

堕落之后神主动施恩，以基督为中保，藉信心领受救恩。历史中以诸阶段性圣约（挪亚、亚伯拉罕、摩西、大卫、新约）施展同一恩典之约。

多特信经强调拣选与有效恩典，与恩典之约一致。

4. 圣经神学主线

贯穿正典的六条主线，彼此交织，汇聚于基督。

1

国度

神的王权：从伊甸托付 → 以色列神治 → 大卫王朝 → 基督宣告「神的国近了」→ 教会作国度见证 → 终末国权完满。

2

圣殿 / 同在

伊甸 → 会幕 → 圣殿 → 道成肉身「支搭帐棚」→ 教会为灵宫 → 新耶路撒冷无需圣殿（神与羔羊为殿）。

3

献祭 / 祭司

流血遮罪制度预表；大祭司基督一次献上自己（来 7–10）；信徒皆祭司，献上属灵祭。

4

应许后裔

女人后裔 → 亚伯拉罕的种 → 犹大支派 → 大卫子孙 → 耶稣基督；谱系不是琐事，是应许线索。

5

余民

审判中神保留属己的子民（以赛亚、哈巴谷、罗马书 9–11）；教会由恩典所存留。

6

弥赛亚

受膏的先知、祭司、君王职分集于一身；受苦仆人与得胜君王——十字架与荣耀的统一。

5. 旧约分卷精读要点

每卷采六栏式：背景 · 写作目的 · 内容提纲 · 神学核心 · 基督指向 · 应用。点击展开。

律法书（创—申）

创世记 — 起源与应许
背景

摩西五经开端；从创造到以色列下埃及，奠定救赎史起点。

写作目的

回答「我们是谁、为何蒙拣选」：创造主立约、罪入世界、应许后裔。

内容提纲

1–11 太古史；12–50 族长叙事（亚伯拉罕、以撒、雅各、约瑟）。

神学核心

创造主权、堕落与审判、拣选恩典、以信称义（创 15:6）。

基督指向

女人后裔；亚伯拉罕之种；约瑟式「受苦升高」预表；犹大权杖（创 49:10）。

应用

信靠应许之神；在罪恶世界中持守圣约身份，拒绝神话化或自然神论读法。

出埃及记 — 救赎与同在
背景

以色列为奴于埃及；神记念与亚伯拉罕所立的约。

写作目的

记述救赎、立约、会幕，显明「我是耶和华」。

内容提纲

1–18 出埃及；19–24 西奈之约；25–40 会幕与荣耀充满。

神学核心

用大能膀臂救赎；约民分别为圣；神与人同住。

基督指向

逾越节羔羊；真吗哪；会幕的实体（约 1:14；林前 5:7）。

应用

救恩先于律法要求；敬拜按神所命定，非按己意。

利未记 — 圣洁与赎罪
背景

会幕竖立后，祭司体系与圣洁法典颁布。

写作目的

教导如何亲近圣洁的神：献祭、洁净、节期。

内容提纲

1–7 祭；8–10 祭司；11–15 洁净；16 赎罪日；17–27 圣洁与许愿。

神学核心

「你们要圣洁，因为我是圣洁的」；无流血则罪不得赦。

基督指向

各类祭的应验；赎罪日大祭司；馨香之祭。

应用

认识罪的严重与恩典代价；追求实际圣洁生活。

民数记 — 旷野与管教
背景

西奈至摩押平原；第一代倒毙旷野。

写作目的

警示不信，显明神信实引领第二代。

内容提纲

1–10 预备；11–25 悖逆；26–36 新一代与地业。

神学核心

不信的恶心；神管教仍守约；铜蛇与代求。

基督指向

铜蛇（约 3:14–15）；磐石随行（林前 10）。

应用

警惕怨言与不信；在试炼中信靠应许。

申命记 — 重申之约与选择
背景

进迦南前，摩西在摩押向新一代讲道。

写作目的

重申约、陈明祝福咒诅、呼召尽心爱神。

内容提纲

1–11 回顾与劝勉；12–26 典章；27–34 祝福咒诅、继承。

神学核心

唯一真神；心约；爱与顺服；先知如摩西者。

基督指向

那先知（申 18；徒 3:22）；诅咒挂木（申 21:23；加 3:13）。

应用

全人敬虔；教导儿女；选择生命。

历史书要点（书—斯）

约书亚记 — 征服与产业
背景

摩西死后，约书亚率民过约旦河。

写作目的

证明神信实赐地；呼召专一事奉。

内容提纲

1–12 征服；13–21 分地；22–24 约的更新。

神学核心

休息与产业；灭绝令的圣战公义语境；约的忠诚。

基督指向

耶稣（同名）带领进入真安息（来 4）。

应用

勇敢遵行话语；除掉偶像；全家事奉耶和华。

士师记 / 路得记 — 败坏循环与恩典一线
背景

无王、各人任意而行；外邦压迫与士师拯救交替。

写作目的

显明需要公义之王；路得显明余民与大卫谱系。

内容提纲

士：循环（犯罪—奴役—呼求—拯救）；路：救赎至亲至大卫。

神学核心

罪的螺旋下滑；神怜悯兴起拯救者；外邦女子归入约民。

基督指向

真士师与君王；波阿斯式至亲救赎者。

应用

离弃相对主义；在黑暗时代做忠信余民。

撒母耳记上下 — 王国兴起与大卫之约
背景

从士师末期到大卫王朝稳固。

写作目的

阐明真君王条件；神与大卫立约。

内容提纲

撒上：撒母耳、扫罗兴衰、大卫兴起；撒下：大卫为王、约、犯罪与后果。

神学核心

人心所看与神所看；大卫之约；罪即使用也受管教。

基督指向

更大的大卫；永远宝座（路 1:32–33）。

应用

敬畏神的领导；悔改如诗篇 51；盼望弥赛亚王。

列王纪上下 / 历代志 — 王朝、圣殿与被掳
背景

所罗门至被掳；代志侧重南国与圣殿敬拜，面向归回群体。

写作目的

以约的标准评判诸王；解释为何亡国；激励归回重建。

内容提纲

联合→分裂→北亡→南亡；代志：谱系、圣殿、改革诸王。

神学核心

拜偶像灭亡；大卫灯火不灭；圣殿同在的圣洁。

基督指向

失败诸王反衬完美之王；圣殿指向基督身体。

应用

领导与敬拜的纯正；历史中读神的信实与审判。

以斯拉—尼希米 / 以斯帖 — 归回与护佑
背景

波斯时期；圣殿、律法、城墙；散居犹大人。

写作目的

重建敬拜与群体圣洁；显明神在隐秘中的护理。

内容提纲

拉：归回建殿；尼：建墙与复兴；斯：普珥日拯救。

神学核心

余民重建；话语中心；护理（providence）。

基督指向

保守弥赛亚谱系；预备道成肉身的历史舞台。

应用

重建从神话语与祷告开始；在压力下持守身份。

7. 新约：福音、教会与终末

四福音书

马太福音 — 弥赛亚君王与天国
背景

面向熟稔旧约的读者；强调应验。

写作目的

证明耶稣是大卫子孙、亚伯拉罕的后裔，天国之王。

内容提纲

诞生与预备；五段讲论（山训等）；受难复活；大使命。

神学核心

天国伦理；教会权柄；旧约应验。

基督指向

以马内利；好牧人；被交权柄的人子。

应用

作门徒、遵守、教导；天国优先于地上忧虑。

马可福音 — 受苦的仆人
背景

传统与彼得宣讲相关；节奏急促（「立刻」）。

写作目的

显明人子权能与十字架道路。

内容提纲

加利利事工；往耶路撒冷；受难周。

神学核心

弥赛亚奥秘；门徒不悟；舍己背十架。

基督指向

人子来服事，舍命作赎价（可 10:45）。

应用

跟随受苦的主，而非荣耀神学捷径。

路加福音 — 拯救临到万民
背景

有序叙述；面向提阿非罗；关注边缘人。

写作目的

叫人确知所闻之道真实（路 1:1–4）。

内容提纲

诞生叙事；加利利；往耶路撒冷漫长旅程；受难复活。

神学核心

圣灵、祷告、贫穷人、赦免、喜乐。

基督指向

寻找拯救失丧者；开启圣经讲自己（路 24）。

应用

怜悯实践；以基督为解经钥匙。

约翰福音 — 神子与永生
背景

较独立的传统；深刻基督论。

写作目的

信耶稣是基督、神之子，因信得生命（约 20:31）。

内容提纲

序言；七神迹/七「我是」；高举的十架；复活显现。

神学核心

道成肉身；三位一体暗示；信心与所见。

基督指向

整卷即基督论高峰；逾越节羔羊。

应用

真信心；住在葡萄树上；彼此相爱。

使徒行传 — 圣灵与宣教

从耶路撒冷到地极

阅读原则

启示文学 + 旧约意象

教会论

比利时信条相关

真教会标记：纯正讲道、圣礼施行、教会劝惩（比 29）。信徒与基督联合，共享恩典管道。

终末

已然未济

国度已闯入；完全成全在再来。身体复活、公义审判、新天新地（海德堡 Q&A 52、57–58）。

盼望

羔羊得胜

启示录中心不是密码，而是敬拜：被杀的羔羊配得权柄；圣徒忍耐守诫命与见证。

初与终；狮子与羔羊；万王之王。

应用

拒绝偶像与淫乱；至死忠心；以敬拜对抗绝望。

8. 信经与信条导图

信经/信条不是高过圣经，而是教会在圣灵引导下对圣经真理的公共总结，用以护卫正统、抵御异端（比利时信条第 7 条：信条服膺圣经）。

普世

使徒信经

三位一体与救恩史纲要：创造、基督降生受苦复活升天、教会、赦罪、复活、永生。

普世

尼西亚信经

力证圣子「与父同质」；反亚流派。读约翰福音与希伯来书的教义护栏。

普世

亚他那修信经

三位一体与基督二性精细表述；敬拜与认信的边界。

欧陆改革宗

比利时信条（1561）

神论、圣经、创造护理、拣选、基督、称义、教会、圣礼、政府等系统认信。

欧陆改革宗

海德堡要理问答（1563）

「罪苦—拯救—感恩」结构；牧养式教义，适合个人与家庭教理。

欧陆改革宗

多特信经（1618–19）

回应阿民念争议：全然败坏、无条件拣选、有限救赎（够用且有效于选民）、不可抗拒恩典、圣徒坚忍。
